# Module 5: FHIR Information Exchange Exercises
This repository provides the initial **FHIR Workflow App** source code for the Module 5 FHIR Information Exchange workshop exercises as part of the FHIR Fundamentals for Australian Developers course.

## Create FHIR Workflow App Sandbox
As part of the Module 5 exercises you can use [StackBlitz](https://stackblitz.com/) to launch an online code development environment using a Web browser, such as Google Chrome — no installation or account required. Simply browse to https://stackblitz.com/github/hl7au/training-ffd-module5 to launch the sandbox and follow the workshop instructor's instructions.

[![Open in StackBlitz](https://developer.stackblitz.com/img/open_in_stackblitz.svg)](https://stackblitz.com/github/hl7au/training-ffd-module5)

Once the app has started, use the **Open in New Tab** button in the preview pane to open the app in its own browser tab — the app stores workshop state in a session cookie, which works best outside the embedded preview.

Alternatively, you may use your usual NodeJS development environment such as Visual Studio Code by cloning this repository. 

    git clone https://github.com/hl7au/training-ffd-module5


## Working version of the FHIR Workflow App
A working version of the FHIR Workflow App is provided in the `working` branch of the repository, which you can access from https://github.com/hl7au/training-ffd-module5/tree/working or checkout in your local clone of the repository.

You can use StackBlitz to launch a working version of the app by browsing to https://stackblitz.com/github/hl7au/training-ffd-module5/tree/working in your Web browser.
